UNAM Student Guide Microsite

Project Overview:
A web-based guide for UNAM students, created as a group project. The site includes a campus map, student tips, and contact information to help new students navigate university life.

Technical Focus:
Although built with Google Sites, the project demonstrates computing principles such as structured content design, logical organization, and collaborative digital development. It reflects an understanding of web technologies and user-centered design.

Live Site:
[UNAM Survival Guide](https://sites.google.com/view/unam-survival-guide/home)

Tools Used:
- Google Sites
- Basic HTML structure and layout planning
- Collaborative content management

My Role:
I initiated the idea and collaborated with group members to design, structure, and publish the site. I focused on logical organization, usability, and clear presentation of information.

What I Learned:
- Applying computing concepts to web design
- Team collaboration and project planning
- Creating accessible digital resources for users
